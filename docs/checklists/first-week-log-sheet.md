# First-Week Log Sheet

One page, seven days, five columns a day. It tells you whether "just shy" is
actually "adjusting nicely" — and if you call the vet, you read it off the
fridge instead of guessing.

How to use: print (or copy the table below), fill a small amount each
evening — about 90 seconds a day. Night 7 gets a mini-review: what changed
from day one, and what the pattern looks like. This sheet pairs with
[chapter 4](../04-week-one-behavior.md) and [chapter 9](../09-call-the-vet-or-wait.md).

## Day 3 mid-week check

Answer these three:

1. Is the pet eating (most of the portion offered)?  Yes / Partly / No
2. Is potty happening (uses box / goes outside / accidents manageable?)
   Yes / Partly / No
3. Compared to day one, hiding is: Better / Same / Worse

Two or more "No / Worse" answers by day 3 → time for a [vet call
today](../09-call-the-vet-or-wait.md). One "no" plus any ! flags also
counts — call, don't push through.
